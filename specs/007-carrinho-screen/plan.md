# Implementation Plan: CarrinhoScreen — Carrinho de Compras

**Branch**: `007-carrinho-screen` | **Date**: 2026-05-24 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/007-carrinho-screen/spec.md`

## Summary

Implementar a tela de carrinho de compras do app Maré de Manguinhos. A tela exibe itens adicionados via ProdutoScreen (armazenados localmente em Zustand), permite remover itens individualmente, exibe o subtotal em rodapé fixo e navega para a CheckoutScreen. Quando vazio, exibe estado amigável com ilustração e botão para a VitrineScreen. O modelo de dados já existe e requer pequenas atualizações para suportar merge de itens com mesmo (produtoId, corte).

## Implementation Sequence

### Step 1: Update types (`src/types/index.ts`)

**What**: Atualizar a interface `CarrinhoStore` com a nova assinatura de `removerItem`.

**Changes**:
- `removerItem(produtoId: string): void` → `removerItem(produtoId: string, corte: Corte): void`
- `adicionarItem` signature permanece a mesma (a lógica de merge vai no store, não na interface)

### Step 2: Update store (`src/store/carrinhoStore.ts`)

**What**: Implementar merge de peso no `adicionarItem` e atualizar `removerItem` para usar par (produtoId, corte).

**Logic for `adicionarItem`**:
```
se existe entrada com mesmo (produto.id, corte):
  incrementar pesoKg dessa entrada
senão:
  adicionar nova entrada
```

**Logic for `removerItem`**:
```
filtrar itens onde NÃO (item.produto.id === produtoId AND item.corte === corte)
```

### Step 3: Implement CarrinhoScreen (`src/screens/carrinho/CarrinhoScreen.tsx`)

**What**: Substituir placeholder por implementação completa.

**States**:
- **Com itens**: ScrollView com cards de itens + rodapé fixo com subtotal e botão "Ir para Checkout"
- **Vazio**: Ilustração + texto + botão "Ver produtos" (navega para Vitrine tab)

**Componentes**:
- Reutilizar `AppButton` com variant `primary` (cor terracota existente) para "Ir para Checkout" e "Ver produtos"
- Cards de itens: implementação inline na própria CarrinhoScreen (são específicos do domínio carrinho, Princípio V)
- Rodapé fixo: View posicionada no final com sombra superior

**Acessibilidade**:
- `accessibilityLabel` em todos os elementos interativos
- Botões com altura mínima de tap target (52px conforme FR-022)

### Step 4: Verify navigation integration

**What**: Confirmar que o badge na aba Carrinho funciona e a navegação para CheckoutScreen está correta.

**Notas**:
- O badge lê `carrinhoStore.itens.length`
- A navegação `"Ir para Checkout" → CheckoutScreen` é delegada ao navegador (rota de checkout a ser definida pela equipe de navegação)
- `"Ver produtos"` navega para a aba Vitrine via `navigation.navigate('Vitrine')`
